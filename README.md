# Olle Marmenlind Portfolio

Personal portfolio and technical writing website: [marmenlind.com](https://marmenlind.com/)

## Development

```bash
# Install dependencies
pnpm install

# Run Tailwind CSS build + Hugo dev server
pnpm run dev

# Run production preview build for performance auditing
pnpm run preview

# Re-run font subsetting (Roslindale woff2 fonts)
pnpm run subset:fonts
```
